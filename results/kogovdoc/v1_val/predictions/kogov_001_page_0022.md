| 연계 대상 | 연계 방안 |
| --- | --- |
| 총남도 스마트시티 데이터허브 | ■ 구축완료 □ 진행중 □ 미구축<br>○ (데이터 기반 서비스 개선)<br>  - 복지 모델1 : 고독사 현황파악을 통한 위험군 설정 및 지속관리<br>  - 복지 모델2 : 독거노인 대화내용 기반 부여군 정서돌봄 AI 모델 구축<br>  - 안전 모델1 : 영상분석 기반 관광/보행사고 예측 시스템<br>  - 안전 모델2 : 범죄 유형 Top5 선정 및 영상분석 기반 탐지 및 경고<br>  - 관광 모델 : 방문객 피드백 기반 콘텐츠 보완 |
| 부여군 통합플랫폼 | ○ (총남도 데이터허브 연동) 스마트 솔루션을 통한 수집데이터를 데이터허브로 실시간 연계하여 데이터셋 구축<br>  - 서비스 만족도, 발전방향, 영상데이터, 사고현황, 독거노인 현황 등<br>○ (AI 서비스 구축) 통합플랫폼 내 AI 서비스 구축을 통해 도시문제 해결<br>  - 수집된 데이터를 통한 지속적인 AI 모델 정확도 보완 |
| 외부 API 연계 | ○ (외부 API를 연계하여 데이터셋 고도화) 구축 데이터셋의 고도화를 위해 GIS, 기상, 소방데이터 접목<br>  - 국토교통부 GIS 데이터 : 사고별 GIS 데이터를 통한 사업 확산지 지정<br>  - 기상청 : 기상별 관광/보행사고 위험도 분석<br>  - 소방안전본부 : 사고발생 후 출동시간 및 이동경로 데이터 기반 우선 신호모델 개발 |
