# ○ 데이터 활용 방안

| 활용처 | 활용 내용 |
| --- | --- |
| 노인보행자 안전 스마트 플 시스템 고도화 | - 노인 유동인구가 많은 시장지역에 구축되는 스마트 플에서 수집되는 영상데이터를 바탕으로 노인객체 탐지 및 사고 직전 행동분석을 통해 사고위험을 더 빠르게 예측하는 영상분석 시스템을 구축하고 수집된 데이터를 기반으로 사고위험지역을 추가로 발굴 |
| 부여군 고독사 위험감지 시스템 구축 | - 읍면 거점을 통해 파악한 독거노인 현황 및 프로그램 참여율 기반으로 고독사 예방이 가능한 정서돌봄 콘텐츠를 추가적으로 제공하며 AI 돌봄서비스에서 수집된 대화 데이터를 통해 고독사 위험군 파악 및 생성형 AI 기반 부여군 고령자 맞춤형 대화형 로봇 제공 |
| 부여 유적지구 관광안전 서비스 | - 수집된 영상데이터 및 범죄데이터를 통해 관광지에서 발생할 수 있는 5대 범죄를 선정하고 영상분석 기반 자동탐지 및 스마트 플 내 음성, 경고등 등의 사고 예방 솔루션 탑재 |
| 정립사지박물관 내 콘텐츠 고도화 | - 방문객 피드백 기반 내부 영상콘텐츠 고도화 및 정립사지 5층 석탑을 활용한 미디어 파사드 구축 |
