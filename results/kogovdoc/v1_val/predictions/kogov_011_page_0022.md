# 인공지능과 CCTV 영상을 이용한 지능형 역학시스템 구축

## 3) 성과지표 측정방안

### ○ 서비스 이용률

| 지표정의 | 인공지능과 CCTV 영상을 이용한 지능형 역학시스템 이용률 |
| --- | --- |
| 목표치 | 2021년 | 2022년 | 2023년 |
| | 85% | 90% | 95% |

| 측정방법 | 서비스 이용률 조사 |
| --- | --- |
| | - 조사 대상자 : EISS 시스템을 이용하는 방역 담당 공무원 |
| | - 조사시기 : 연 1회(12월) |
| | - 조사방법 : 전문기관(NIA) 설문지 활용 |
| | - 조사내용 : EISS 시스템 이용자 중 영상 AI 분석 이용자 조사 |
| | - 측정산식 : 인공지능과 CCTV 영상을 이용한 지능형 역학시스템 이용 건수 / EISS 시스템 이용 건수 * 100% |
| | - 목표치 설정근거 : 2019 전자정부서비스 이용실태조사 결과 보고서, 행정안부, 2019(상) 행정서비스 이용율 98%를 목표치로 설정함 |
| | * 조사방법, 측정산식 등에 대해서는 추후 전문기관과 협의하여 조정가능 |

### ○ 이용자 만족도

| 지표정의 | 인공지능과 CCTV 영상을 이용한 지능형 역학시스템 이용자 만족도 |
| --- | --- |
| 목표치 | 2021년 | 2022년 | 2023년 |
| | 81점 | 85.5점 | 90점 |

| 측정방법 | 이용자 만족도 조사 |
| --- | --- |
| | - 조사대상자 : EISS 시스템을 이용하는 방역 담당 공무원 |
| | - 조사시기 : 연 1회(12월) |
| | - 조사방법 : 전문기관(NIA) 설문지 활용 리커트 5점 척도 조사 |
| | - 조사내용 : 영상 AI 분석 시스템의 만족도 및 불편 사항 등 |
| | - 측정산식 : 만족도를 5점 척도로 표시하고 그 결과를 100점 만점으로 환산 (Σ응답자 점수, 1~5점) / (응답자수×5점(만족))×100 |
| | - 목표치 설정근거 : 유사 시스템인 방법용 CCTV 만족도(2018년 동두천시, 81%, 892점/1,100점)를 초기년도 목표치로 설정, 2023년 최종만족도는 90%로 설정 |
| | * 2018년 동두천시 방법용 CCTV 설문조사 결과 |
| | 구분 | 만족 (5점) | 다소만족 (4점) | 보통 (3점) | 다소불만족 (2점) | 불만족 (1점) | 소계 |
| | 설문수 | 98 | 56 | 52 | 8 | 6 | 220 |
| | 한산점수 | 490 | 224 | 156 | 16 | 6 | 892 |
| | 만족도 | 81점(892 / (220×5)) |
